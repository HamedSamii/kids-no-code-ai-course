# A No-Code and AI Course for Kids and Teens

Children learn how a language model works, then design a bot's personality and build it without writing code.

> **Case study.** Source code is private. The business problem, the design decisions and the stack are documented here.

## The problem

Young learners hear about AI everywhere but rarely get to see how it works or build anything with it.

## What was built

- **Intro to how language models work**, in plain language
- **Lesson on bot personality**: how tone and instructions change behaviour
- **Hands-on no-code building** at the learners' pace

## Stack

No-code bot builders · LLM tools

## Status

Teaching materials prepared for an academy.
